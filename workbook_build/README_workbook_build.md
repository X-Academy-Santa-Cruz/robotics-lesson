# ROV Builder's Workbook — build scripts

These are the Node.js scripts that generate the X Academy ROV workbook Word
documents. They were built in a Claude cloud workspace (ephemeral), so they are
stashed here in the project so a future chat can recreate the `.docx` output.

## What produces what

- **`build_workbook.js`** — the MASTER content. Every section of the workbook is
  a `children.push( ... )` block in here. This is the file you edit to change
  wording, add/remove sections, etc. (~142 KB.)
- **`gen_content.js`** — slices `build_workbook.js` into per-section pieces using
  a `map` array of `[name, pushLine, closeLine]` (1-based line numbers of the
  `children.push(` line and its matching `);`). **If you edit
  `build_workbook.js` and line numbers move, this map must be recomputed** or the
  slices will be wrong. Running it regenerates `wb_content.js`.
- **`wb_content.js`** — generated by `gen_content.js`; the per-section content the
  builders import. (Do not hand-edit; regenerate it.)
- **`wb_common.js`** — shared helpers. Key function `makeMultiSectionDoc(parts, opts)`:
  each part becomes its own Word section with `pageNumbers:{start:1}` to restart
  numbering; `footerForTag(tag)` builds tagged "section-page" footers (e.g. `7-1`);
  the `pad` flag adds a blank filler page **as its own footer-less Word section**
  so blank pages carry NO page number.
- **`build_combined.js`** — builds the single combined workbook
  (`X_Academy_ROV_Workbook_Complete.docx`, ~71 pages): full-page cover, static
  contents, all sections. Two-pass measure-and-pad so each section ends on an even
  page AND starts on the front of a fresh sheet (odd physical page) for printing
  with dividers. **This is the usual target.**
- **`build_split.js`** — builds the per-section documents instead of one combined
  file.
- **`svgs.js`** — generates the six diagram SVGs (`svg_*.svg`). These were then
  rasterized to the `img_*.png` files that `build_workbook.js` embeds.

## Page-numbering scheme (section-page)

Tags: front matter `0`, sections `1`–`10`, Appendix `A`, Reference `R`, Prompts `P`.
Footer reads `<tag>-<n>`, e.g. `4-4` = 4th page of section 4. Blank filler pages
are footer-less (no number). Sections are padded to end on an even page and to
start on an odd physical page (front of a sheet).

## Assets (bundled here)

- `logo_xacademy.png`, `logo_coe.png`, `photo_IMG_6059.jpg` — cover art, read by
  name by `build_combined.js`. (Originals are also project uploads.)
- `img_*.png` — the six rasterized diagrams embedded in the workbook.
- `svg_*.svg` — the SVG sources for those diagrams (in case you want to re-render
  at a different size). The SVG→PNG rasterize step was run ad hoc, not scripted;
  any SVG→PNG tool works (e.g. `rsvg-convert -o img_X.png svg_X.svg` or cairosvg).

## Rebuild recipe (fresh workspace)

```bash
# 1. put all these files in one directory and cd into it
# 2. install the one dependency
npm install docx                       # built with docx; Node v22 used

# 3. (only if build_workbook.js was edited) recompute the slice map in
#    gen_content.js, then regenerate wb_content.js:
node gen_content.js

# 4. build the combined workbook
node build_combined.js
#    -> X_Academy_ROV_Workbook_Complete.docx

#    or build per-section docs:
node build_split.js
```

The builders write absolute paths like `/home/claude/...`; if your workspace
home differs, adjust the paths at the top of `build_combined.js` /
`build_split.js` (the `fs.readFileSync(".../logo_xacademy.png")` etc.) or just
run from a directory where those asset names resolve.
