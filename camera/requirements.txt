# Python packages for the camera lesson.
#
# On the Raspberry Pi, every package this lesson needs is provided by apt and
# installed by the course setup script (setup.sh), so there is nothing to pip
# install here -- just run the lessons with the shared venv active:
#   source ~/robotics-lesson/.venv/bin/activate
#
# Provided by apt (installed by setup.sh):
#   python3-opencv   OpenCV -- reads the camera and makes JPEGs (both scripts)
#   python3-flask    Flask  -- tiny web server used by camera_simple.py
#   python3-click    click  -- command-line options used by stream_server.py
#
# ---------------------------------------------------------------------------
# If you ever set this lesson up OFF the Pi (e.g. on a laptop) without those
# apt packages, you can pip install the equivalents instead:
#   opencv-python-headless
#   flask
#   click
